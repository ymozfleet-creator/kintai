# ケーニッヒ武蔵小金井 本店勤怠管理システム

**ケーニッヒ武蔵小金井 本店勤怠管理システム**は、打刻・勤怠記録・稼働時間調整・給与試算までを2ファイルで完結する、店舗向けの軽量な勤怠管理システムです。サーバー不要・GitHub Pagesでそのまま動作します。\n\n- 営業時間:11:00〜19:30(インビスは19:00まで)/定休日:火曜日 — 出勤表・シフト希望に反映済み

## 構成

| ファイル | 役割 | 想定利用者 |
|---|---|---|
| `index.html` | 打刻画面(出勤/退勤ボタン+本日の出勤状況のみ) | スタッフ全員 |
| `admin.html` | 管理ダッシュボード(PINロック付き) | 管理者のみ |
| `gas.gs` | スプレッドシート連携用スクリプト(Google Apps Scriptに貼り付け) | 管理者(初期設定時のみ) |

公開URLのトップ(`https://<ユーザー名>.github.io/<リポジトリ名>/`)を開くと打刻画面が表示されます。管理画面は `/admin.html` にアクセスするか、打刻画面フッターの「管理」リンクから開きます。

## 公開手順(GitHub Pages)

1. GitHubで新しいリポジトリを作成(例:`kintai`)。※無料プランでは Pages は Public リポジトリのみ利用可(Private リポジトリでの Pages 公開は有料プランが必要)。いずれの場合も公開URL自体は誰でもアクセス可能な点に注意
2. `index.html` `admin.html` `README.md` の3ファイルをリポジトリ直下にアップロード
3. リポジトリの **Settings → Pages** を開く
4. Source を **Deploy from a branch**、Branch を **main / (root)** に設定して Save
5. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

## 初期設定

- **管理者PIN 初期値:`0000`** — 公開後、必ず admin.html →「従業員・設定」タブで変更してください
- 初回アクセス時にデモデータ(従業員5名・前月実績・当月予定シフト)が自動投入されます
- 実運用の開始時は「従業員・設定 → データ管理 → 全データ削除」→ 従業員を登録し直してください

## 主な機能

- **打刻**:出勤/退勤ボタン。日またぎ勤務(夜勤明け退勤)対応。退勤時に休憩を自動設定(実働6h超45分/8h超60分、修正可)
- **本日の出勤(シフト+打刻状況)**:今日シフトがある人を打刻前から一覧表示。「本日のシフト 18:00〜22:30|出勤前→勤務中→退勤済」と、今日誰が何時から何時までいるかが打刻画面のトップで即答できます
- **出勤表・シフト希望(横型シフト表)**:打刻画面に週間出勤表を横型シフト表で常時表示(行=スタッフ、横軸=時刻9:00〜22:00固定、日ごとのブロックを月曜から縦に配置・前週/翌週切替)。各人の行に横バーが伸び、バーの位置と「10-19:30(8.5h)」の表記で誰が何時から何時まで働くかが一目で読めます(短いシフトはバーの右横にラベル表示)。営業時間11:00〜19:30は白地+金線、開店前後は斜線、インビス閉店19:00は点線の縦線、火曜は「定休日」行、本日ブロックは金枠+現在時刻の赤線で強調。確定=塗りつぶし/承認待ち=点線「希望」/自分=金枠。名前を選択すると「今週のあなたのシフト」サマリーが出て、各日の「＋」行のタップで勤務希望を申請できます(自分のバータップで取り消し/変更申請)
- **シフト表(管理画面)**:「シフト表」タブに同じ横型の週間シフト表を表示し、シフト作成がこの1画面で完結します。全スタッフの行を毎日表示し、空欄クリック→シフト追加/確定バークリック→時間の変更・削除/点線「希望」バークリック→その場で承認。下の一覧で承認・却下・一括承認と履歴確認、承認待ち件数はタブにバッジ表示
- **勤怠記録**:月別一覧・手入力追加・修正・削除・CSV出力
- **稼働調整**:従業員ごとの月間上限(h)に対する 予定/実績/残り枠/着地予測/状態バッジ。シフト一括入力は時間帯指定(拘束時間から自動休憩を控除して実働換算)、予定シフト表(従業員×日)での時間調整も即時反映
- **給与試算**:アルバイト=時給×実働+割増、正社員=基準内賃金÷月平均所定労働時間で残業単価を算出。時間外×1.25/深夜+0.25(変更可)
- **KPI**:本日の出勤人数/総労働/残業合計/人件費見込を管理画面トップに表示

## スプレッドシート連携(オプション)

打刻・記録の修正・削除を、Googleスプレッドシートにもリアルタイムで蓄積できます(端末内localStorageとの二重管理)。設定手順は同梱の `gas.gs` ファイル冒頭のコメント、または利用マニュアル第8章を参照してください。

- 「勤怠記録」シート:常に最新の状態(修正・削除も反映)
- 「打刻ログ」シート:すべての操作履歴(追記のみ・監査ログ)
- 通信失敗時は端末内のキューに保持され、回復後に自動再送されます
- 連携を後から有効にした場合は、管理画面の「全記録を一括送信」で過去分をまとめて反映できます

## データの保存について(重要)

- データは**ブラウザのlocalStorage**に保存されます。`index.html` と `admin.html` は同一ドメインに置くことでデータを共有します
- **端末・ブラウザを変えるとデータは引き継がれません**。打刻用の端末を1台に固定して運用してください
- 定期的に「データ管理 → バックアップ(JSON保存)」でバックアップを取得してください
- PINロックは簡易的な画面制御であり、厳密なセキュリティではありません。複数端末運用や本格的な保護が必要になった場合は Firebase 等のサーバー認証型への移行を推奨します
